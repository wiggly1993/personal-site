# Mission

Build a personal portfolio website showing Beniamin Jablonski's AI / deep-learning projects.

- **Look & feel:** as close as possible to apple.com product pages (iPhone/MacBook). Lots of whitespace, huge confident headlines, alternating light/dark full-width sections, subtle scroll animations, translucent sticky nav. Details: [design-colors-type.md](design-colors-type.md), [design-layout-motion.md](design-layout-motion.md).
- **Modular:** adding or removing a project = adding or deleting one folder. Adding or removing a homepage section = editing one line in a config file. See [modularity.md](modularity.md).
- **Cheap:** fully static site, free hosting on Cloudflare Pages. Only cost is a domain (about €10–15/year). See [deploy-cloudflare.md](deploy-cloudflare.md).

GitHub repo (prepared, empty, private): https://github.com/wiggly1993/personal-site.git
