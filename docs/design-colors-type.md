# Design: colors & type (authentic Apple style)

All values live in `src/styles/tokens.css`.

**Colors**
- Light bg `#ffffff`, alt light `#f5f5f7`
- Dark bg `#000000`, dark alt `#1d1d1f`
- Text `#1d1d1f`, secondary text `#6e6e73`
- Link / accent `#0071e3`
- Alternate light and dark sections down the page.

**Type (Inter variable)**
- Hero 56–96px with `clamp()`, weight 600–700.
- Letter-spacing −0.015em to −0.03em on big headings.
- Section titles 40–64px.
- Body 17–21px, line-height 1.47.
- Gradient text on hero and featured titles (subtle, e.g. blue → purple).
